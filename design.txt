Treat typography as a primary design element, not a final polish step. The supplied references use a rounded/geometric modern sans-serif character with bold display headings, compact uppercase labels, readable body copy, and prominent statistic numbers.

Typography direction:

* Prefer a geometric/rounded sans-serif feel similar to Poppins or Avenir Next.
* Use the existing dependency-free font setup; do not install a font package solely for a minor visual difference.
* Use strong 700–800 weights for display and section headings rather than 900 everywhere.
* Use 400–600 weights for body and supporting text.
* Use compact uppercase labels with deliberate tracking around 0.8–1.6.
* Use tighter letter spacing on large headings and statistics.
* Keep body line height around 1.45–1.55× font size for comfortable mobile reading.
* Keep button labels medium-bold and compact.
* Use deep navy and electric-blue text hierarchy so important content feels connected to the blue gradient identity.
* Avoid making every text element the same size or weight.

The implementation uses Avenir Next on iOS when available and the native sans-serif family on Android, with a shared typography scale in constants/typography.ts.
